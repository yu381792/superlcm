# 0.5.11 摘要语义改造

DSH 接管压缩、Claude 接管压缩和只存档不接管压缩的后台摘要，使用相同的事实、时间与决策规则。借鉴 LosslessClaw 的分层写作与查回设计；没有把其每轮上下文组装方式直接移入 SuperLcm。

## 摘要内容

底层记录这一段结束时的目标、状态、决定、理由、限制、例外和未完成事项。第一次合并保留时间顺序，明确旧决定被什么替换、为什么、替换范围是什么；更高层保留仍然有效的决定及其演变、关键细节和未解问题。层级高不代表可以删除授权、否定和例外。

明确区分用户批准、助手建议、工具观察和验证结果。失败、取消、待执行不能变成成功；局部例外不能变成全局批准。每个摘要是其来源范围结束时的历史快照，而非今天的指令。旧摘要仅帮助理解新段里的指代；不能替代新证据。

叶摘要从校验后的完整原始记录投影正文，不从 UI 搜索预览提取。支持 Claude、Codex、Pi、Hermes 和普通消息中的工具调用与结果，包含错误状态、调用标识、来源时间和正文换行。思考块、原生压缩的 replacement_history 和行政记录不当作新对话。单条过大原文仍以明确标记的头尾摘录处理，必须留下原文编号和查回需求；这不等于所有细节都进入了摘要。

合并包含每个子摘要的全文及节点/范围，不再每块裁到3600字。完整合并输入超过限制则失败，不偷偷裁剪。API、Claude CLI及内置模块传递可用的结束状态；截断或超长输出拒绝保存，原文保留。Pi 纯文本 CLI 没有提供可核查的模型停止原因，仍只能验证进程成功、非空和长度，不能声称检测了所有截断。

## 上下文与来源

只存档模式不替换主会话上下文；Codex 原生压缩仍由 Codex 执行。Claude 继续沿用门槛替换和最近原文保留机制；来源边界无法确定或摘要未跟上时交还原生压缩。

DSH 后台草稿和阈值固定范围一次提交的机制保留。树合并目标仍来自总预算，而非统一套用1200 tokens。native compactRegion/compactNow 三参数入口从真实 surface 消息的 durable ID、完整内容和连续范围推导来源，核验已有检查点与数据库 compaction ID，按已有子节点层级选择写作规则。后台模型请求仍独立使用辅助身份，替换宿主附加的一条写作指令，保留重放前缀与工具历史。摘要写作禁止调用工具，只标注需要读者查回的事实。

多个历史摘要拼接时加固定的先后顺序和 recall node 标签。标签是可确定重建的包装，既不调用模型也不升层。旧的逐块精确拼接及新的标签拼接都经过内容验证，任意前缀仍不接受。DSH 异步提交使用新版历史参考外框；宿主原生入口保留宿主外框格式，摘要正文和召回规则采用新政策，并附加来源范围与历史快照查证说明，避免旧外框把状态当作现在的用户指令。

## 迁移及验收边界

新任务 digest 包含政策版本，合并 digest 包含完整子摘要正文哈希；旧任务结果不能作为新任务提交。历史节点保持原文、来源和摘要，不批量重写，不花钱重算。新叶节点从现有覆盖末尾继续生成，后续新合并使用新规则。旧摘要已丢掉的信息需要读原文或另行批准重建，改提示不能补回来。

结构测试覆盖：失败结果进入模型输入、字面空白完整、完整子摘要尾部例外、任务失效、截断及超长结果拒绝、Claude 内置保存、DSH 原生层级/子图、预算提示与一条写作指令、新旧检查点重建和透明包装。安装的真实 DSH 宿主参与运行时测试，模型回复为本地模拟；没有操作生产会话或调用付费模型。

这些检查证明输入、路由、存储和边界机制，不证明真实模型的摘要语义质量。真实模型验收应使用相同合成原文分段、一级摘要与再合并输出，对照原文检查：没有把未批准变已批准、失败变成功、取消变待执行，没有遗漏约束/例外/原因或改写数值；无法确定时有出处而非猜测。不能用输出关键词出现率代替这项人工语义核查。

上游比较与固定源码出处见 [LosslessClaw 设计评估](LOSSLESSCLAW-DESIGN-REVIEW-20261004.md)。

## 本轮结构验收

0.5.11 的 `npm run validate`（含语法检查）140/140，`npm run test:dsh-runtime`37/37。独立审查发现的六项入口/来源/预算/停止状态问题以及 Hermes 数据库行编码、null 行问题均修复后复核关闭；另实测宿主 compactNow 两轮及冷重建。原文、模型配置、阈值和现役会话未被这组测试修改。

真实模型的待执行样例与判定依据保存在 `test/fixtures/summary-semantics.json`：四段叶摘要和一次合并共五次调用。每个所选模型单独运行，不能把一个模型通过说成所有模型通过；结果还需对照整段原文逐项阅读确认。
