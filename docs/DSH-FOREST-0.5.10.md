# DSH 摘要森林修复（0.5.10）

旧版把多段摘要拼接进一个检查点时也增加层级，持续对话形成了逐轮增长的包装链。0.5.10 将发布检查点与摘要层级分开：拼接只包装，不概括、不升层；四段同层摘要达到组数后由模型真实概括才升层。总预算按实际发布的单个检查点计算，超预算时允许真正的进一步概括。后台准备仍不改主上下文，到门槛固定范围并准备完成后只提交一次，新增内容留待下一轮。

旧包装只有在逐块重建与子节点内容完全一致时才透明展开；图片、文件和文本块边界均须一致。旧摘要正文、编号和原始会话不改动，派生目录隐藏包装并重新计算真实层级、子节点及递归覆盖。逻辑成员与物理选区分别验证，同一旧检查点只计算一次；遗漏或重复引用摘要成员会拒绝发布。

后台按真正进入对话上下文的用户消息、助手消息和工具结果统计覆盖，包含普通替换消息；运行事件、常驻规则与压缩检查点单列。覆盖按确切来源记录计算，阅读范围不等于所有中间记录均已摘要。摘要条带每个节点只画一个可点击阅读范围，保留精确来源数量，避免长会话生成数万按钮。

只读真实样本 #fd80e 的6343条记录中，有效原文1709条，摘要覆盖1582条，最近127条未覆盖，较早有效原文无遗漏。其35个历史节点全部保留，5个透明包装退出可见目录，可见30个节点；真实层级从原显示8层恢复为3层。没有调用模型重写这些历史摘要。

另修复旧会话头读取时补默认 delegationDepth=0 被误判身份变化的问题。只放行字段缺省与默认0的等价，其余身份变化仍拒绝。归档失败现明确报告到对应会话，恢复后可在原档案继续补录，不新造会话身份。

归档插件在宿主启动后才加载时，也会补录在线会话、已有归档的冷会话及持久层尚未归档的冷会话；不依赖下一条新消息来补录。持久层列举失败会报告，但不会阻塞已知会话的归档恢复。真实宿主回归验证三类来源均完整补录、逐条原文一致。

兼容旧宿主已完成但没有 SuperLcm 标记的压缩摘要。只有开始、摘要、检查点和成功结束完整，检查点正文逐块相等且来源记录齐全时才补索引；复用已有迁移节点的身份，补回后续摘要的子引用。已推进到最新位置的索引也会无损补这段历史，不重写摘要正文。宿主明确替换过的工具结果旧版本单列保留，不计待摘要；仅认替换范围内的来源，范围外依赖不会被剔除。

V9 主线程 6862 条真实事件的隔离重建补回第 1043 条已提交摘要，原 50 个节点只增加 1 个，后续引用恢复且原摘要正文逐一不变。较早未摘要有效原文为 0，未摘要 67 条全部位于最新尾部；30 条旧版本单列。此修复没有调用模型。

会话列表按 DSH 原始末事件时间排序，补录历史不算新活动。末事件时间缓存与记录游标一起保存，重复补录不读取旧正文；归档15项回归通过，包括历史补录不会把活跃会话挤到后页及增量读取边界。

验证：基础测试133项通过，DSH真实宿主运行时35项通过；六轮独立检查点提交的层序为1、1、1、2、2、2，只有一次四段同层合并。独立审查补充了图片/文件保真、文本块边界、多父重复来源和单个检查点真实预算四项回归，修复已复核通过。测试使用本机已安装的DSH宿主与隔离记录，不触发量化任务或付费摘要。

活动游标与时间更新共用写事务，避免并发补录把新活动时间倒退。旧插件索引若保留同一摘要的重编号前来源，迁移会显式报告差异并保留两侧档案，不覆盖已纠正索引，也不因此卸载当前压缩和归档插件。

层级图不再留下无说明的白色缺口。没有本层节点的区间按确切消息覆盖标成其他层覆盖、待摘要、部分覆盖或非摘要记录；能确定一个实际覆盖节点时显示其层数并链接到该摘要。图下方分别提示历史覆盖和最新待摘要状态。图形补充覆盖关系，不增造摘要节点、不改原文或压缩行为。界面回归覆盖了跨层覆盖链接、混合区间和真实历史缺口不能误报全覆盖三种情况。
