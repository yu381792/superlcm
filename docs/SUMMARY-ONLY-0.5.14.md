# 0.5.14：默认只接入后台摘要

所有接入默认只负责原文归档、后台分层摘要和查询。当前对话的上下文压缩由宿主负责。Claude Code 的可选接管仍保留，但安装和更新接入会恢复为关闭；DSH 的默认 SuperLcm 组件不注册压缩服务。

DSH 的独立摘要使用用户保存的自定义 API，选项在接入卡片和 DSH 的 SuperLcm 插件设置中共用。没有可用 API 时保留原文并显示关闭，接入不要求压缩模型，也不猜测聊天模型的凭据。启动时追溯和导入历史不调用模型；实时回合结束才调度已配置的后台摘要。

旧 DSH 接入迁移会撤销自有全局接管块和预设继承块，保留用户修改的模型、其他插件及原生压缩参数。每个使用方式都经过宿主 `--dump-config` 验证：原生自动压缩存在、SuperLcm 只归档，模型配置前后一致。仅当原生引擎确实缺失时补原生 Basic 实例。

管理接入新增取消接入。Codex 和 Claude 通过官方命令撤销自有 MCP；Claude 插件停用并恢复原生窗口；Hermes 经宿主配置函数撤销自有登记和钩子；Pi 扩展移入配置备份；DSH 撤销自有激活并核实原生压缩。已存原文、摘要和会话身份保留。持久开关立即拦住缓存入口的自动归档，现有摘要任务在下一提交边界拒绝迟到结果；旧会话的查询工具需要重载后消失。

DSH 摘要输入来自完整事件，保留工具请求、调用 ID、失败状态和来源时间，排除压缩检查点、私有推理与行政事件。旧原生摘要按准确来源序号计算覆盖，新摘要补实际空洞，不使用旧范围上界跳过未摘要消息。归档摘要树的层数表示真实合并深度，原生压缩检查点不进入这棵树。

摘要默认段长 48,000 字符、四段合并。已有设置保留；改变粒度会让旧批次在提交前停止，后续按新设置规划。字符数不等于 token 数，超长单条事件仍保留完整原文，摘要中的节选会提示查回原文。

验证覆盖真实 DSH CLI 接入和取消、原生压缩复原、模型保留、完整工具证据、稀疏旧摘要空洞、混合钩子、并发 MCP 替换、host/API 摘要取消以及提交事务边界。独立审查报告的工具事实、迟到提交与配置并发问题均已修复。
