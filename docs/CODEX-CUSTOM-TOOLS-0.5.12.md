# 0.5.12 Codex 工具来源补全

0.5.11 的原文投影识别 `function_call` / `function_call_output`，遗漏了 Codex 的 `custom_tool_call` / `custom_tool_call_output`。后两类原文仍完整归档和可查回，但传给摘要模型的内容为空。模型因此可能只看到助手关于执行的说法，看不到工具的真实失败结果。

本次交叉核查只统计本机记录的类型与字段，没有把生产会话正文发给独立审查模型。合成记录重现了这两类投影为空的问题。

修复统一识别两种调用及结果：自定义调用读取字面 `input`，普通函数调用读取 `arguments`；保留 `call_id`、名称、来源时间和完整结果。调用仍标为请求，不能证明执行成功。新增测试通过完整导入及 `summaryWork` 核对失败结果进入叶摘要输入，并验证原文仍逐字可查。

本次修复不替换 Codex 主会话上下文，也不重写历史摘要。旧摘要若已经漏掉执行结果，需要查回原文核实；不能声称新投影已经修复旧摘要的内容。
