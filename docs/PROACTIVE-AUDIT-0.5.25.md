# 0.5.25 主动审查

2026-10-10 对完整版和 DSH 独立版进行独立审查。审查者使用合成对话和假模型沿数据读取、分段、模型流、保存及上下文替换追踪，不依赖用户提交新 issue。复现的问题已修复，并转为固定回归。

| 已复现问题 | 修复 | 适用版本 |
|---|---|---|
| DSH 模型只输出正文、没有真实正常结束，仍能替换上下文；未知结束原因仍可写归档 | 必须有唯一真实 stop；拒绝工具开始/增量/结束、结束后内容、截断、错误或取消。旧未提交草稿失效 | 完整版 0.5.25、独立版 0.5.28 |
| 独立归档漏认工具结果 message.toolCallId，后续摘要一直停住 | 按宿主真实结构闭合工具组，含失败结果 | 独立版 0.5.28 |
| 叶摘要分段拆开请求与失败结果 | 按原始结构跟踪工具关联；完整组结束才关段；并行组、字符串编码均有回归 | 完整版 0.5.25 |
| 文本导入未按真实用户语言生成约束 | 从有角色标签的原始文本提取用户语言，排除助手语言 | 完整版 0.5.25 |
| 同一失败批次在多个自动任务中反复购买 | 数据库持久化退避，连续失败暂停；后台工作不能绕过，配置变化或手动生成可恢复 | 完整版 0.5.25 |
| CLI 超时只发 SIGTERM，子进程忽略后调用无限等待 | 超时/输出超限立即拒绝，并在短暂宽限后强制结束自有摘要子进程 | 完整版 0.5.25 |

模型流验证的首次修复在独立复核中漏了“工具块开始”；复核新增真实宿主形状的探针后补齐。这条探针已加入接管与独立归档回归。不会将首次测试全绿当作覆盖所有输入的证明。

发布者运行 [完整发布检查](RELEASE-VERIFICATION.md)。本轮验证包含源码回归、真实 DSH 运行时、本地 npm 解包后的 CLI/MCP、特殊字符路径中的官方 DSH 安装升级，以及两版共用模块一致性。模型均为假模型，原文逐条校验，未让用户任务承担故障注入。

本轮实机平台是 macOS；Windows/Linux 自动测试保持关闭，没有本轮实机结果。模型生成是否忠实保留所有授权、否定、因果与长期约束，不可能仅凭确定性假模型全部证明；涉及精确决定时仍须召回原文。该限制由发布者如实说明，不能代替故障复现和修复责任。
